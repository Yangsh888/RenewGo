# RenewGO - 面向 TypeRenew 的轻量外链安全插件

本插件是一款面向 TypeRenew 的轻量外链安全插件，适配 PHP 8 与 MySQL 8，提供外链改写、安全提示页、白名单直跳、跳转签名校验、访问限频与跳转日志能力。

## 功能特性

- **外链统一改写**
  - 支持改写文章正文中的外部链接
  - 支持改写评论正文中的外部链接
  - 支持改写评论作者链接
  - 支持前端动态改写与渲染后兜底改写
  - 可统一补充 `nofollow`、`noopener`、`noreferrer`

- **安全跳转链路**
  - 支持"安全提示页"模式
  - 支持"直接 302 跳转"模式
  - 支持关闭改写，保留后台规则管理
  - 跳转前使用签名与时效校验，避免链接参数被伪造
  - 可配置新窗口或当前窗口打开外链

- **白名单与直跳控制**
  - 支持域名白名单
  - 支持泛域名白名单，如 `*.example.com`
  - 支持域名加路径规则，如 `example.com/path`
  - 支持完整 URL 白名单
  - 可限制直跳模式仅允许白名单目标

- **访问限制与日志**
  - 支持按 IP 统计每小时最大跳转次数
  - 超限后自动阻止继续跳转
  - 支持关闭、基础、完整三档日志级别
  - 支持后台查看最近跳转日志
  - 支持日志自动清理与手动清空

- **后台运维能力**
  - 提供规则测试工具
  - 支持白名单导出与导入
  - 支持缓存配置与面板分页条数设置

## 适用场景

- 基于 TypeRenew 构建的个人博客、内容站和轻量网站
- 希望统一接管站内外链跳转链路的站点
- 需要在访问外链前增加安全提示页的场景
- 需要对白名单外链直跳、其余外链提示或拦截进行统一管理的站点

## 安装方式

1. 将插件目录上传到站点的 `/usr/plugins/` 目录
2. 确保目录名称为 `RenewGo`
3. 登录后台，进入"控制台 -> 插件"
4. 找到并启用 `RenewGo`
5. 启用后，在左侧导航中进入"外链安全"面板完成配置

## 面板说明

插件后台面板主要包含以下模块：

- **基础配置**
  - 插件启停
  - 跳转模式
  - 改写范围
  - `rel` 策略
  - 新窗口打开与直跳白名单限制

- **提示页与安全限制**
  - 提示页标题
  - 自动跳转秒数
  - 跳转签名有效时间
  - 每小时每 IP 最大跳转次数

- **规则管理**
  - 外链白名单维护
  - 规则测试
  - 白名单导出
  - 白名单导入

- **日志与维护**
  - 日志级别
  - 日志保留天数
  - 后台日志每页数量
  - 最近跳转日志查看
  - 日志清空

## 工作方式

### 外链改写

- 插件会识别站内 HTML 中的外部链接，并将其改写为站内 `/go/...` 跳转地址
- 默认不会改写本站同域链接，也不会改写命中白名单的目标链接
- 可按需启用前端动态改写与页面输出后的兜底改写，以覆盖更多主题或动态内容场景

### 跳转模式

- 在"安全提示页"模式下，用户会先进入中间提示页，再通过带签名的跳转地址离站
- 在"直接 302 跳转"模式下，可选择是否仅允许白名单目标直跳
- 若目标链接无效、签名校验失败或访问过于频繁，插件会输出提示页而不是直接跳转

### 白名单规则

支持以下规则形式：

```text
example.com
*.example.com
example.com/path
https://example.com/path
```

说明：

- `example.com` 表示整站域名白名单
- `*.example.com` 表示匹配该主域名下的子域名
- `example.com/path` 表示匹配指定域名下的路径前缀
- `https://example.com/path` 表示仅匹配完整 URL

## 目录结构

```text
RenewGo/
├── assets/              # 后台面板与前端改写脚本
├── view/                # 提示页视图模板
├── Plugin.php           # 插件入口、规则改写与配置管理
├── Action.php           # 跳转处理、规则测试与日志动作
└── Panel.php            # 后台外链安全面板
```

## 注意事项

- 本插件提供的是轻量外链安全能力，不替代专业风控、反钓鱼服务或浏览器安全能力
- 直跳模式若开启"仅允许白名单"，请先配置白名单，否则未命中的外链将无法直跳
- 若主题或其他插件也会重写外链，请留意重复改写或链路冲突
- 启用完整日志后，目标链接与来源信息会记录得更详细，应结合日志保留策略使用
- 前端动态改写与渲染后兜底改写用于增强兼容性，通常只需按实际主题情况选择启用
